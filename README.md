# Verhuischecklist

Een simpele, mobielvriendelijke checklist voor onze verhuizing en de gastouderopvang van Marin.

- Vinkjes worden automatisch bewaard op het apparaat (in de browser).
- Met de knop **Vinkjes delen** stuur je een link met jouw vinkjes; wie die link opent, kan ze samenvoegen met de eigen lijst.

## Online zetten met GitHub Pages

1. Maak op github.com een nieuwe repository, bijvoorbeeld `verhuischecklist`.
2. Klik op **Add file → Upload files** en sleep alle bestanden uit deze map erin (`index.html`, `manifest.webmanifest`, de drie `.png`-bestanden en deze README). Klik op **Commit changes**.
3. Ga naar **Settings → Pages**. Kies bij *Source* voor **Deploy from a branch**, branch **main**, map **/ (root)**, en klik **Save**.
4. Na een minuut of twee staat de checklist op `https://<jouw-gebruikersnaam>.github.io/verhuischecklist/`.

## Op je telefoon zetten

Open de link in Safari (iPhone) of Chrome (Android) en kies **Zet op beginscherm**. De checklist opent dan als een app.

## Let op

- Een GitHub Pages-site is openbaar voor iedereen die de link kent (bij een gratis account). De vinkjes zelf staan alleen op jullie eigen telefoons, niet online.
- Wis je de websitegegevens van je browser, dan zijn ook je vinkjes weg. Stuur jezelf af en toe een deel-link als back-up.
- Pas je later items aan in `index.html`? Je bewaarde vinkjes blijven staan. Deel-links die vóór de wijziging zijn gemaakt, kloppen dan niet meer: stuur elkaar daarna een nieuwe link.
